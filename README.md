# ☕ Brew Haven – Coffee Shop Landing Page

A modern and responsive **Coffee Shop Landing Page** developed as part of the **Oasis Infobyte Web Development & Designing Internship (Level 1 – Task 1)**.

## 📌 Project Overview

Brew Haven is a visually appealing landing page built using **HTML5** and **CSS3**. The website showcases a coffee shop with a clean, responsive design and user-friendly interface.

## 🚀 Features

- Sticky Navigation Bar
- Hero Section with Call-to-Action
- Featured Menu
- Why Choose Us Section
- About Us Section
- Customer Reviews
- Contact Section
- Responsive Footer
- Mobile-Friendly Design
- Responsive Layout using CSS Flexbox & Grid

## 🛠️ Tech Stack

- HTML5
- CSS3
- Flexbox
- CSS Grid
